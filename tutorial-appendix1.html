从0开始的 JE 航械入门 APPENDIX

下面整理了一批能显著提升搓机体验的模组，按用途分成四类。星级仅为推荐程度，具体以实际需求为准。

1. 地毯 Carpet 相关

Carpet 地毯

⭐⭐⭐⭐⭐

添加了很多实用的调试指令，例如创造穿墙等。

适用版本：1.11.2 - 最新版本
下载 GitHub 中文百科

Carpet TIS 扩展

⭐⭐⭐⭐

添加了更多实用调试指令。

适用版本：1.14.4 - 最新版本
下载 GitHub 中文文档

Carpet AMS 扩展

⭐⭐⭐⭐

添加了更多实用调试指令。

适用版本：1.14.4 - 最新版本
下载 GitHub 中文文档

Yet Another Carpet Addition 毯上添花

⭐⭐⭐⭐⭐

除了添加更多实用调试指令之外，YACA 还为 Carpet 系列添加了一个图形用户界面，提供了收藏 carpet 指令、中文搜索命令等实用功能。

适用版本：1.20.3 - 1.21.11
下载 GitHub 中文文档

CarpetGUI

⭐⭐⭐⭐

提供了比 YACA 更强大的 Carpet 图形用户界面。

适用版本：1.19 - 26.1.2
下载 GitHub
中文文档：下载界面往下翻。

Subtick

⭐⭐⭐⭐⭐

微时序必备模组。

适用版本：1.17 - 26.2
下载（1.17 - 1.20.1） 下载（1.17 - 最新） GitHub 中文文档

2. Masa 全家桶等客户端模组

MaLiLib

⭐⭐⭐⭐⭐

所有 masa 模组的前置模组。

Litematica 投影

⭐⭐⭐⭐⭐

味大无需多盐。

适用版本：1.12.2 - 最新版本
下载 GitHub

Tweakeroo

⭐⭐⭐⭐

提供长期夜视、快捷放置、快速交互、自动换手、手持物品替换等超多实用功能。

适用版本：1.12 - 最新版本
下载 GitHub

TweakerMore

⭐⭐⭐⭐

提供更多 Tweakeroo 没有的功能与增强。

适用版本：1.14.4 - 最新版本
下载 GitHub

MiniHUD

⭐⭐⭐⭐

显示各类信息。

适用版本：1.8 - 最新版本
下载 GitHub

Lucidity 我的视界

⭐⭐⭐⭐

终极客户端可视化工具。

适用版本：1.21 - 1.21.10
下载 GitHub

3. 各类可视化模组

Pistorder 活塞推动顺序可视化

⭐⭐⭐⭐⭐

右键活塞底座，查看推动的方块和顺序。

适用版本：1.14.4 - 最新
下载 GitHub

Scheduled Tick Visualizer 计划刻可视化

⭐⭐⭐⭐

显示计划刻事件的信息（优先级、子顺序等）。

适用版本：1.20.1 - 1.21.10（Modrinth 里找不到的话到 GitHub 里找）
下载 GitHub
